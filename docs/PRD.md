# StudyFlow iOS — Product Requirements (MVP)

## Goal
Native iOS client that lets a student plan and track a study day offline-first, with the same core model as the web StudyFlow.

## MVP Scope
- Today screen with blocks & tasks
- Create / edit / complete blocks and tasks
- Local persistence
- Basic progress & streak
- Simple onboarding
- Settings placeholder

## Out of scope for first slice
- Full sync with backend
- Widgets & Live Activities
- Sign in with Apple
- Kanban / full Calendar / Pro paywall
